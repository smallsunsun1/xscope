# ADR-0001：分离控制面和数据面

- 状态：Accepted
- 日期：2026-09-04

## 决策

采用独立 Rust 数据面和 Go 控制面。控制面初期为模块化单体；Kubernetes 协调器保持独立进程。网关通过版本化快照读取模型、策略和价格相关的只读配置，通过异步事件输出用量，不在每个请求中同步调用控制面。

## 原因

模型 API 的流式长连接、尾延迟和故障域与账号计费完全不同。同步依赖控制面会把数据库或发布故障放大到推理请求路径。另一方面，过早把账号、目录、配额、账单拆成多个服务会引入分布式事务和交付成本。

## 后果

- 网关必须定义配置过期和 last-known-good 行为。
- 配额需要本地快速判断与全局强约束之间的折中。
- usage 采用至少一次投递，因此计量和账本必须幂等。
- 跨面契约必须版本化并具备兼容性测试。
